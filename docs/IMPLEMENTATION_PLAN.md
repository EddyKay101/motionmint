# Verifiable milestones

1. **Foundation — complete:** separate app, installable manifest/service worker, responsive shell, versioned open-category project model.
2. **Discovery — complete:** category filters and six visually distinct template definitions covering the initial set.
3. **Vertical editor — complete:** title, scene add/remove/reorder, bilingual auto-direction fields, durations, theme controls, and three output ratios.
4. **Local media — complete for slice:** private session-only image/video underlay and audio preview; no external transfer.
5. **Preview — complete for slice:** reusable GSAP full-composition transition, live edits, playback controls, media underlay, and reduced-motion handling.
6. **Persistence — backend foundation complete:** debounced local autosave, offline restore and D1 synchronization through device-scoped APIs.
7. **Template catalogue — backend foundation complete:** D1 records with draft/published/archived states and protected administration endpoints. Next: administration UI and authentication.
8. **Rendering contract — queue complete:** MP4 requests create durable render jobs. Next: deterministic Chromium frame renderer, FFmpeg worker, progress and download.
9. **Private media — intentionally local:** R2 remains disabled. Next: authenticated, private uploads with signed access when accounts are introduced.
10. **Production hardening — next:** automated interaction tests, font bundling for broader Arabic coverage, offline update UX, media validation/transcoding, and accessibility audit.
